# UART Transmitter and Receiver using Verilog HDL
## Objective
To design and simulate UART transmitter and receiver modules using Verilog HDl in modelsim
## Features
- UART TX Module
- UART RX Module
-Testbench verification
-UART Top for connecting Rx and Tx
Waveform analysis
## Tools used
 - Verilog HDL
-ModelSim
- Digital Logic Design
## Result
Successfully transmitted and received 8-bit data: 10100101
